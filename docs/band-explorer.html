Settings - the mod's switches

Each field is a value under "alfred-mods" in a settings file. Pick one per file, or leave it unset: for each field the mod takes the highest file with a valid value - .claude/settings.local.json, then .claude/settings.json, then ~/.claude/settings.json, then a choice an earlier command stored, then the default. A bad value is skipped as if absent. Mid-session REC never falls because a file went quiet: it holds until that file says a lower level, or the next claude run. A change to any file redraws the band within seconds.

What each file holds

Keep the JSON valid. Claude Code reads a settings file whole or not at all: one that does not parse is skipped entirely - its permission rules included, not only "alfred-mods". At a session's start it stops on a 'Settings Error' dialog; mid-session the file drops out with no warning - which is why REC holds its level when the file that set it goes quiet.

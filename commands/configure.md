argument-hint: "[.alfred-mods|.alfred|default]"

The alfred-mods hooks did not answer this command, so tell the user it did nothing here. To set it by
hand, add `"alfred-mods": { "plansFolder": "<value>" }` to `.claude/settings.json`, where `<value>` is `.alfred-mods`,
`.alfred` or `default`.
